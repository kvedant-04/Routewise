# Plan 11.4: Absolute Reliability Layer (Critical Patch)

<objective>
Upgrade backend + frontend into a fully deterministic, crash-proof system by enforcing forced JSON mode, safe extraction, deep normalization, and strict frontend guards.

Purpose: Eliminate ALL remaining edge-case failures and blank-screen crashes.
Output: Final production-grade reliability layer.
</objective>

<context>
- backend/main.py
- frontend/src/App.jsx
- .gsd/SPEC.md
</context>

<tasks>

<task type="auto">
  <name>Backend Critical Patches (JSON Mode & Deep Normalization)</name>
  <files>backend/main.py</files>
  <action>
    - **Force JSON Mode**: Add `response_format={"type": "json_object"}` to OpenRouter calls.
    - **Safe Extraction**: Implement a retry-based `extract_json` with non-greedy regex fallback `r"\{.*\}"`.
    - **Deep Normalization**: Inside a model validator or post-process loop, enforce:
        - `start_time` fallback to `time` or "09:00".
        - `duration_mins` conversion (string to int) or default 60.
        - Fallbacks for `activity`, `place`, `notes`, and `cost`.
    - **Strict Validation Upgrade**: Reject if days != requested, or < 3 activities per day.
    - **Hard Fallback Upgrade**: Ensure hardcoded fallback is high-quality and schema-perfect.
  </action>
  <verify>Run `pytest` or manual API test to verify "time" -> "start_time" mapping and JSON mode enforcement.</verify>
  <done>Backend response is 100% deterministic and schema-pure.</done>
</task>

<task type="auto">
  <name>Frontend Critical Patches (Safe Parse & Global Guards)</name>
  <files>frontend/src/App.jsx</files>
  <action>
    - **Safe Parse Layer**: Wrap `JSON.parse` in try/catch with explicit `setError`.
    - **Global Null Guard**: Return an `<ErrorState />` if `parsed.days` is not a valid array before any render.
    - **Safe Events Hardening**: Enforce NO undefined fields, fallback strings, and strict type casting (duration=number, time=string).
    - **Empty State UI**: If `safeEvents.length === 0`, show "Unable to generate itinerary. Please try again."
  </action>
  <verify>Break the JSON string manually in `App.jsx` and verify the ErrorState renders instead of crashing.</verify>
  <done>Frontend is immune to malformed backend strings and empty arrays.</done>
</task>

<task type="auto">
  <name>Map Safety Final Patch</name>
  <files>frontend/src/components/MapIntelligence.jsx</files>
  <action>
    - Add a high-level guard: Only render the `MapContainer` if `validPoints.length > 0`.
    - Else show a "No map data available" placeholder.
  </action>
  <verify>Provide 0 valid points to the map and verify the placeholder renders.</verify>
  <done>Map never crashes on zero-coordinate datasets.</done>
</task>

</tasks>
